Smart Grocery Waste Tracker – Functionality

Overview of the key operations and logic of the project. 


1. User Registration & Login
   - Users create accounts and log in securely.
   - Uses Django’s built-in authentication with hashed passwords.

2. Add & Manage Grocery Items
   - Add items with name, quantity, expiry date, and category.
   - Edit or delete items anytime.
   - Data is saved to the GroceryItem model in MySQL.

3. Expiry Reminders
   - Daily background task checks for items expiring in 2 days.
   - Sends email or in-app notifications.

4. Mark Items as Wasted
   - Move expired items to WastedGroceryItem with reason and date.

5. Waste Analytics Dashboard
   - Aggregates data and displays charts using Chart.js/Plotly.

6. Search & Filter
   - Quickly find items by name, category, or expiry range.

7. Responsive Web Interface
   - Django templates + Bootstrap provide a mobile-friendly layout.
